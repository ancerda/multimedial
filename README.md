## Unidad I. Hipervínculo

####  Mi primera página:

``` html 
<!DOCTYPE html>
<!-- Indica al navegador que este documento usa HTML5 -->

<html>
<!-- Inicio del documento HTML -->

<head>
<!-- Sección donde van metadatos, título y estilos -->

<meta charset="UTF-8">
<!-- Define la codificación de caracteres para que se vean bien tildes y símbolos -->

<title>Multimedial</title>
<!-- Título de la página que aparece in la pestaña del navegador -->

<style>
        /* Estilo general del cuerpo */
        body {
            font-family: Arial, sans-serif;
            background-color: rgb(31, 17, 17);
            margin: 10px;
            display: flex;
            justify-content: center;
            align-items: center;
            font-size: arial, sans-serif;
            color: rgb(203, 179, 200);
        }

        /* Contenedor principal */
        .contenedor {
            width: 80%;
            margin: auto;
        }

        /* Sección o bloque */
        .bloque {
            background-color: rgba(37, 35, 38, 0.66);   
            margin:auto;
             margin-top: 50px;
            width: 60%;
            padding: 50px;
            border-radius: 10px;
        }

        /* Imagen */
        .bloque img {
            width: 80%;
            height: auto;
            display: block;
            margin: 0 auto; /* Centrado horizontal */
        }

        /* Encabezado */
        .bloque h2 {
            margin-top: 30px;
        }

        /* Texto */
        .bloque p {
            line-height: 1.5;
        }
    </style>
</head>
<!-- Fin de la sección head -->

<body>

    <!-- Contenedor principal -->
    <div class="contenedor">

        <!-- BLOQUE 1 -->
        <div class="bloque">
            <img src="img/Invasor_parasito.jpg" alt="Descripción de la imagen">
            <h2>Invasores Espaciales</h2>
        </div>

        
<nav>
<a href="obras.html">Obras</a>
<a href="contacto.html">Contacto</a><br>
</nav>
</body>

</html>
<!-- Fin del documento HTML -->

```
